# ZCode RC 隐私政策（本地自用版）

**一、本 APP 不收集任何数据**
- 无统计 SDK、无广告、无自建服务器
- 不上传任何信息到开发者或任何第三方

**二、数据全部存储在本机**
- 会话 Cookie：仅用于连接你自己的桌面端（zcode.z.ai），相当于桌面窗口的临时钥匙
- 任务快照与通知历史：仅存 APP 私有目录，可随时在"设置 → 数据"中清空
- 崩溃日志：仅存本机，仅在你主动查看时展示
- 用量页登录态：bigmodel.cn 的 Cookie，仅本机保存

**三、网络通信对象仅限**
- zcode.z.ai：ZCode 官方远程控制页面
- bigmodel.cn：智谱官方用量页面

以上均为智谱官方服务，页面内数据的处理遵循智谱官方的隐私条款；本 APP 不经手、不转发、不存储这些通信内容。

**四、权限用途**
- 网络权限：连接上述官方服务
- 通知权限：任务状态提醒
- 前台服务：实时模式保活（默认关闭，需手动开启）
- 相机权限：仅在"扫码配对"时用于本地识别二维码，相机画面不存储、不上传，识别完成或退出扫码页即释放

**五、品牌与开源说明**
- 本项目为非官方第三方工具，与 Z.ai 无隶属关系
- 代码开源时，仓库不包含任何官方品牌资产（图标等）与账号凭据
- 官方图标版权归 Z.ai 所有，仅限本地个人使用
