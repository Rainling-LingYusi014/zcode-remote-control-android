# 开源准备清单（发布分发版之前逐项执行）

- [ ] 官方图标移出仓库与 APK：`res/mipmap-*` 的 ic_launcher* 全部替换为原创图形（当前官方 Z 底牌仅本地自用）

- [ ] `res/values/colors.xml` 的 ic_launcher_bg 同步换
- [ ] 检查 docs/截图/README 不含官方图标图片

## 2. 凭据与个人数据隔离

- [ ] `.gitignore` 加入：`keystore.jks`、`凭据_签名.md`、`build/`、`tools/build/`、`docs/` 中含个人路径的文件（或脱敏）
- [ ] 代码内无个人路径硬编码（`E:\.ZCode` 仅出现在 toolchain 路径，构建脚本可参数化）
